# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Client-Side Security Model

This application executes strictly in the user's browser. Files are processed in memory and are never uploaded or transmitted to any server.

## Reporting a Vulnerability

If you discover a security vulnerability or privacy concern, please do not open a public issue. Instead, report it privately via GitHub Security Advisories or contact the repository owner directly.
